Field

com.alecdorrington.eunomia.model.Field
See theField companion object
final class Field[-X, B](val name: String, read: X => Option[B])(using B: Scalar[B])

One named, typed field of the items in a list: how to read it from an item, and the vocabulary for filtering and ordering by it. The name is what queries refer to, so a server and a client describing the same list must agree on it.

val rating = Field.of[Book]("rating", _.rating) // A `Field[Book, Long]`.
val query  = ListQuery(rating >= 50L && rating.present, List(rating.descending))

Type parameters

B

The type of the field's values, which may be absent from some items.

X

The type of the items.

Value parameters

name

The name queries refer to this field by.

read

Reads this field's value from one item, if it has one.
