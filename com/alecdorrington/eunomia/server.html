SqlLists.type
final class SqlLists(val profile: JdbcProfile, wholeUpTo: Int = ..., maxWindow: Int = ...)

Answers ListQuerys over the rows of a database table. A short list is sent whole, for the browser to query as it pleases without asking again; a long one is filtered, ordered and paged in SQL, so that only the window asked for is ever loaded. Which applies is decided here, per request, so no caller need know.

Answers ListQuerys over the rows of a database table. A short list is sent whole, for the browser to query as it pleases without asking again; a long one is filtered, ordered and paged in SQL, so that only the window asked for is ever loaded. Which applies is decided here, per request, so no caller need know.

The results agree with those of a Schema over the same items: absent values (NULLs) fail every comparison and come last in either direction, and text is sought ignoring case.

val lists   = SqlLists(H2Profile)
val columns = lists.columns(Book.schema)(
 lists.text[Books]("name")(_.name.?),
 lists.whole[Books]("rating")(_.rating), // Already optional.
)
lists.answer(books.filter(_.owner === user).sortBy(_.id), columns, query)

Value parameters

maxWindow

The most rows sent in any one window of a longer list, however many are asked for.

profile

The Slick profile of the host application's database.

wholeUpTo

The most rows a list may have to be sent whole.
