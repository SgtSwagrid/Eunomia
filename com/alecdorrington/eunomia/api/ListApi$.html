ListApi

com.alecdorrington.eunomia.api.ListApi
object ListApi

Endpoint inputs and outputs for lists served to a browser. Add input to any endpoint to have it take a ListQuery as query parameters, and reply with reply:

GET /api/things?filter={"field":"name","contains":"x"}&sort=-rating,name&offset=0&limit=50
